Наиболее общие АТД:
- элемент (Element)
- комбинация (Combination)
- координата (Coordinate)
- игровое поле (Field)
- главный игровой цикл (MainLoop)

1) Element представляет собой абстрактную ячейку на игровом поле. Ключевой запрос - количество очков за его удаление.
2) Combination представляет собой набор объектов типа Element. Ключевой запрос - количество очков за сборку.
3) Coordinate отвечает за расположение Element на игровом поле. С помощью координат можно узнать находятся ли два элемента рядом,
чтобы их можно было поменять местами.
4) Field объединяет объекты типа Element по координатам. Ключевая команда - перестановка двух элементов по их координатам.
Ключевой запрос - наличие потенциальной комбинации. При вызове команды перестановки поле реагирует изменением структуры элементов
при возникновении комбинации.
5) MainLoop отвечает за проведение одной игры от создания начального поля до завершения игры.

В общем виде игра проходит так: MainLoop создаёт Field, пока у Field существует хотя бы одна потенциальная комбинация, то
ожидается ввод пары Coordinate переставляемых Element, если в результате перестановки образовалась комбинация, то поле реагирует
изменением структуры элементов (удаление элементов комбинации, смещение элементов, заполнение освободившихся мест), если перестановка
не приводит к комбинации, то она не осуществляется, элементы остаются на своих местах. Когда потенциальных комбинаций не осталось,
игра завершается.
