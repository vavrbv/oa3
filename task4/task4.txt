Отдельные специфические структуры данных не потребуются.
Из основных классических структур данных будут нужны:
- Grid - двумерный массив для представления игрового поля из элементов;

- Stack - стэк для хранения ходов (введённые пользователем координаты и результат перестановки).
Позволит, при необходимости, добавить возможность отката ходов пользователя;

- Set - множество доступных комбинаций для проверки текущего собранного пользователем набора элементов.
После перестановки указанных пользователем элементов, образованные ими наборы элементов можно нормировать
по координатам и проверить, что такой нормированный набор существует во множестве комбинаций.
