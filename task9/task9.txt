- Игровое поле (Field):
Игровому полю следует добавить команду заполнения пустых ячеек.
Для оптимизации хранения элементов следует использовать массив из готовых объектов - создаются один раз при создании
объекта поля, в таком случае, в ячейках поля достаточно хранить лишь индексы элементов в массиве, индекс -1 соответствует
пустой ячейке. Для заполнения ячеек случайными элементами следует использовать любой генератор псевдослучайных чисел, позволяющий
получать целые числа из равномерного распределения (модуль random). Так, при создании игрового поля запускается последовательное
заполнение ячеек случайными индексами элементов. При удалении элементов в результате возникновения комбинации, в их ячейку
записывается индекс -1, команда заполнения пустых ячеек заполняет такие ячейки случайными индексами из массива элементов.

- Главный игровой цикл (MainLoop):
Создаётся один раз при запуске приложения, вместе с ним, композиционно, создаётся игровое поле. При перезапуске
игры предыдущее игровое поле заменяется на новое. К главному игровому циклу, через агрегацию, добавляется компонент
визуализации, который отвечает за вывод игровой информации на экран пользователя (предложение ввода и подсказки, игровое поле,
статистика). Компонент статистики создаётся композиционно вместе с главным игровым циклом, при перезапуске игры он пересоздаётся.
Одна итерация главного игрового цикла выглядит следующим образом: выводится подсказка по вводу, ожидается ввод игрока, ввод игрока
проверяется на допустимые операции, ввод передаётся игровому полю (если это координаты для перестановки) или выполняется самим циклом,
ход добавляется в статистику, в конце хода вызывается компонент визуализации для представления результатов: вывод игрового поля,
статистики, сообщения о завершении игры.

- Компонент статистики (Statistics):
Компонент статистики добавляется для учёта ходов игрока (координаты переставляемых элементов и результат перестановки).
Статистика описывает последовательность игровых ходов и предоставляет команду для добавления нового хода, запросы для получения
сводных результатов: числа ходов и количества очков.

- Игровой ход (Move):
Игровой ход добавляется для описания действия игрока в рамках одной итерации игрового цикла: введённые координаты и количество очков.
Объект игрового хода создаётся игровым полем и возвращается через запрос как описание действия и его результата.

- Координата (Coordinate):
Объект координаты создаётся как результат пользовательского ввода координат двух элементов для перестановки.


Основные обрабатываемые события:
- Ввод координат двух элементов для перестановки.
Описывает координаты двух элементов, которые передаются игровому полю для перестановки, игровое поле
должно проверить, что координаты не выходят за границы, то есть принадлежат некоторым ячейкам и, что они находятся рядом друг с другом,
то есть доступны для перестановки.

- Перезапуск игры.
Требует реакции главного игрового цикла, пересоздания игрового поля и объекта статистики.

- Завершение игры.
Если на игровом поле отсутствует потенциальная игровая комбинация, то образуется событие завершения игры,
в конце игры игроку должна быть выведена статистика за эту игру. Единственным допустимым вводом здесь является полный выход
из приложения или перезапуск.

- Ошибки пользовательского ввода.
События ошибки пользовательского ввода появляются при некорректном вводе координат или команд, все ошибки пользовательского ввода
должны обрабатываться с выводом на экран игроку самой ошибки и допустимых команд и форматов координат.


Типовые сценарии:
- Перестановка двух элементов.
Перестановка двух элементов может приводить только к двум ситуациям: образование комбинации, отсутствие комбинации.
В случае образования комбинации, элементы, которые её образовали удаляются, к ходу игрока добавляются очки. Если после перестановки
комбинации нет, то структура игрового поля не должна меняться, переставляемые элементы остаются на своих местах, количество очков игрового
поля равно нулю.

- Запуск и перезапуск игры.
При запуске и перезапуске игры должны заново создаваться объекты игрового поля и статистики, данные предыдущей игры удаляются,
история ходов считается пустой.

- Добавление хода в статистику.
При добавлении хода в статистику количество ходов увеличивается на единицу, итоговая сумма очков увеличивается на количество очков хода.
Так как за ход может быть получено ни одного очка, то при добавлении такого хода общее число очков не увеличивается.
