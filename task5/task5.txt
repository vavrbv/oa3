1) Фабричный метод (Factory Method) - для создания элементов разных типов через единый интерфейс.

2) Команда (Command) - для команд перезапуска и завершения игры.

3) Итератор (Iterator) - для обхода игрового поля и элементов комбинации.

4) Строитель (Builder) - для динамического добавления игровому полю дополнительных характеристик.
